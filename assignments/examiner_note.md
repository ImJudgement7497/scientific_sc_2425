# Examiner Note

The ZIP file contains:
- `solution.pdf`: Full pdf of the solutions for the entire exam
- `Q1`: Directory for Q1
- `Q2`: Directory for Q2
- `Q3`: Directory for Q3
- `Q4`: Directory for Q4

In all `Q` directories are the full work done. In `Q1` and `Q2` there are only written files as they required no coding. In `Q3` and `Q4`, there are the full source code, header files and scripts used. Each directory also contains a pdf relating to the question, however all the same information is in `solution.pdf`. For the coding questions, the individual solutions will guide you through the rest of the directory. 

For Q4, it is important to note that the source code is in `src` for both serial and parallel (each having the majority of the work done in `main.cpp`) and the header files are in `include` both for serial and parallel. I highly recommend using the `Makefile` if you will be compiling and executing binaries as it will take all this into account. 

All solutions were written in Markdown for ease of transferring things like code snippets and images. However, the formatting on turning a Markdown file to a PDF file means that there are a lot of pages to this. Everything that is written is relevant, and the number of pages is due to the amount of space that the formatting left to fit everything in coherently.
